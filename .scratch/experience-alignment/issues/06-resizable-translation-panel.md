# 06 — 可调整尺寸的翻译面板

**What to build:** 翻译面板每次以默认尺寸打开，在完整翻译结果到达后按最终内容自动扩展一次，再允许用户从右边、底边和右下角临时调整尺寸。

**Blocked by:** None — can start immediately.

Status: ready-for-agent

- [ ] 面板每次以 `360 x 220` 打开；小视口下安全裁剪至可见范围，不读取或写入上次的面板尺寸。
- [ ] 翻译加载、字段流式返回和自动调整期间均禁止手动调整；只有完整翻译结束且自动调整动画完成后才启用右边、底边和右下角手柄。
- [ ] 完整翻译结束后面向所有模板字段测量一次最终内容，按“先宽后高”得到目标尺寸，只自动调整一次；短内容不缩小面板。
- [ ] 自动调整最大尺寸为 `560 x 420`，同时受当前面板左上角到视口右边、底边 `8px` 边距限制；自动调整期间左上角位置保持不变。
- [ ] 自动调整使用平滑的宽高过渡，并遵守 `prefers-reduced-motion`；测量和尺寸写入避免逐帧重复布局。
- [ ] 动画完成后用户可临时手动调整，调整时左上角位置保持不变，最大宽高仍受当前视口和 `8px` 边距限制。
- [ ] 关闭后再次划词从默认尺寸重新开始，自动尺寸和手动尺寸都不跨面板打开保留。
